# Тестирование и отладка (для ИИ-агентов)

Дополнение к AGENTS.md — как проверять расширение живьём и не гоняться за ложными ошибками.

## Смок-тест в Chrome с залогиненным аккаунтом

Незалогиненный смок скрывает целые классы проблем (воспроизведение, поиск, скрейпинг vk.ru и их ошибки). Минимум для содержательных правок — залогиненный прогон:

1. `./build.sh`. Если работаешь в worktree — скопируй `dist/chrome_extension` в `dist/` основного клона: chrome-devtools MCP ставит расширения только по путям внутри workspace root.
2. MCP `install_extension` → `new_page` `https://vk.ru/` → **пользователь логинится сам** (куки нужны расширению).
3. `trigger_extension_action` → выбрать страницу попапа в `list_pages`.
4. Что проверять: попап открылся с данными; табы переключаются; воспроизведение (клик по треку → прогресс/время идут, трек из поиска переключает текущий); поиск (запрос → все секции выдачи); модалки (настройки, «лайк»; открытие, закрытие, Esc); `list_console_messages` попапа и service worker.
5. Визуальные вещи (вёрстка, отступы) — скриншот пользователю: модель изображения не читает, оценивает размеры скриптом (см. ниже).

## Бейзлайн консоли — эти ошибки НЕ регрессии

После воспроизведения/поиска консоль попапа заполняют ~800 ошибок CSP
`Executing inline event handler ... blocked` (две директивы: страницы расширения и `script-src 'self'` от vk.ru) плюс CORB-notice. Это pre-existing поведение скрейпинга `vk-client` (A/B подтверждено на сборках 7.x и 8.x), функциональность не страдает.

Правило: сравнивай консоль с этим бейзлайном по составу и количеству, а не ожидай «пусто». Новые типы ошибок — уже сигнал.

## Отладка состояния попапа

- Состояние вкладок/страниц переживает закрытие и релоад попапа (`storageAtom` → `chrome.storage.local`). Завис на странице ошибки/вкладке — сбрось напрямую:
  `chrome.storage.local.set({ activeTab: { tab: 'general' | 'my-music' | 'explore' | ..., value: '' } })`
  (значения — enum `ContentTab` в `packages/common/src/types.ts`).
- Замер вёрстки — `evaluate_script` + `getBoundingClientRect()`: ширины ячеек, зазоры между соседями (`next.left - prev.right`), переполнение текста (`span.right - cell.right > 0`). Так ловятся наезды/слипание без визуального просмотра.

## Референс vk.ru

Страница музыки vk.ru (`/audios<id>`) в автоматизированном браузере грузит каталог только в активной вкладке (foreground + reload; SPA-ленивость). Удобна как референс вёрстки: замеряй их плитки тем же `evaluate_script`.
